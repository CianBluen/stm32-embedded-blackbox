# stm32-embedded-blackbox

## 1. Project Introduction

基于 STM32 的嵌入式设备运行数据记录系统。
实现传感器数据采集、环形缓冲区缓存、
异常事件检测及 SD 卡数据存储。

## 2. Features

- Periodic sensor data acquisition
- Circular buffer
- Event-triggered recording
- SD card data logging
- UART command interface
- Error handling

## 3. Hardware

- MCU: STM32xxxx
- Sensor: MPU6050
- Storage: SD Card
- RTC: xxxx
